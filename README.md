# ⚡ Serverless Lead Intake Engine

A lightweight, plug-and-play Vanilla JavaScript form that bypasses traditional backends and sends lead data directly to a Discord channel via Webhooks.

**Engineered by [Arjumand Labs](https://github.com/FakhareArjumand)**

## 🚀 Features
* **Zero Backend Required:** Fully serverless architecture using Discord Webhooks.
* **Spambot Trap:** Built-in honeypot field that silently drops automated bot submissions.
* **Client-Side Validation:** Custom JS validation overrides native HTML5 behavior for a smoother UX.
* **Premium UI:** Multi-step frosted glass interface with Arjumand Labs `#060E20` styling.

## 🛠️ Usage
1. Replace the `DISCORD_WEBHOOK_URL` in `src/intake.js` with your own Discord integration link.
2. Drop the `index.html` and `intake.js` files into any static hosting site (Vercel, GitHub Pages, Netlify).
3. Start receiving leads instantly.
